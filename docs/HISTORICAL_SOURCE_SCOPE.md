# 2015–2019 上櫃來源與分類證據

依已採用的2015–2022分年補資料計畫，將下載年份下限延伸到2015。分類函式、股票池層級、固定規則與模型參數均不改動。2020–2022已保存來源不重新生成。

官方歷史依據：

- [2013-12-11中華民國證券市場編碼原則](https://www.twse.com.tw/staticFiles/marketAnnounce/setAnnounce/1021217-1020026025-1.pdf)：公開發行與上市／上櫃股票沿用四位數代碼；特別股與其他商品另有編碼規則。
- [2009-11-12證交所公告](https://www.twse.com.tw/staticFiles/marketAnnounce/setAnnounce/0980028877.htm)：2009-12-15後新發行ETF／TDR／封閉基金改六碼，舊發行仍可保留四碼。

因此四碼只列規則候選，不表示已核实普通股。既有ISIN／CFI非普通股證據優先於四碼規則；CFI留白、類型衝突與未知列都保留。已核實子集合須另報敏感度，不能把候選池的績效當作純普通股績效。

這些是目前取得的官方歷史規則與回溯分類證據，不是原始公告時點證券主檔。下載年份逐年驗收，行情存在不能代替完整停牌主檔。缺失資料不補零；原始行情、日曆、公司行動與法人皆須各自重播及封存驗證。

2015–2019由`configs/tpex_history_scope.json`明列範圍，來源程式拒絕範圍以外年份；股票池既有政策不變。先完成2020法人來源，再按2019到2015順序下載。
