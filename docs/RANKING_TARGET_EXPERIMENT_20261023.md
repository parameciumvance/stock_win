# 一次固定的排名目標建模實驗

使用者採納：用既有價量資料，實際重訓「預測60日報酬幅度」與「預測同日未來報酬名次」兩種目標，檢查是否改善跨年穩定性。本輪只比較目標，不增加資料來源、特徵或參數搜尋。這是目標函數診斷，不是假定發現新的經濟資訊。

唯一來源是已核實的2023-01-03至2026-10-02凍結價格。沿用原十項量價特徵及固定HistGradientBoostingRegressor參數，兩模型共用每一列訓練資料、權重、股票池、日期及成本。排名目標採同一訊號日已知標籤的平均同分百分位；仍用平方誤差迴歸，不冒稱pairwise排序演算法或報酬／機率校準。

原完整基本面共同矩陣不在本地。因此本輪明定只要求量價完整的普通股池，兩個目標都在此池重新訓練，另比較同池動能／波動排序。不能拿本輪與舊全特徵報告的數值差直接歸因於排名目標。

三個年度折：2023訓練→2024評估；2023–2024訓練→2025；2023–2025訓練→2026。每折剔除未在前一年底及首個訊號收盤前成熟的60日標籤，完整日期群同時切分。所有年度都已研究，不是新獨立留出。

每日Top10%與月度Top15均先按分數選股、字串代碼同分排序，不看未來完整性、不替補。任何選中端點未知，該方法當日／月均值維持未知。直接比較只用四法皆完整的同日期並列出排除數；同時保留全部原選股與未知結果。端點是次市場日開盤至第60市場日收盤，內部停牌不縮短市場時計。

主要比較為每日排名目標樹減報酬目標樹的平均成本後相對0050端點差。20／60／80市場日circular block區間保留原成熟訊號日位置及其中缺值，不壓縮缺日。主要區塊60日，5000次，樣本不足不縮短區塊；月度樣本少不作可靠顯著性結論。

續研門檻在訓練前固定：三個年度主要增量都為正，且至少兩年度同時勝過動能及波動。這只是本輪是否值得延伸的描述性資源門檻，不是交易資格或顯著性判定。恰好六次固定參數訓練；未過門檻即結束這條目標支線，不換參數、年份、持有期或子群追回績效。

協定：`configs/ranking_target_protocol_20261023.json`。使用`research_pipeline.py`順序執行來源核驗、矩陣建置、三年度訓練、獨立分數／選股／端點核對與報告；最後封存、備份取回核對SHA／CRC／manifest。原模型、協定與報告保留，不產生有效訊號或實際訂單。
