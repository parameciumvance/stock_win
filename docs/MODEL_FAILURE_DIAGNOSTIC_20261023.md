本輪沿用已訓練的60日量價／全特徵Ridge與梯度提升樹，對照原共同池的動能、波動排序。保留七法原月度Top15名單；不重訓、不改模型參數、不增加新策略。這是診斷，不會使已研究的2024–2026變成獨立留出。

2. 以原始固定價格重算每筆月度選股的次日開盤至第60市場日收盤端點。交易日取全市場聯集；不因個股或0050停牌縮短期間。原選中結果未知，整月均值未知，不刪股或補零。
3. 比較六法皆有已知結果的共同日，不以每法不同缺值日期拼接比較。月度比較另用各配對的共同完整月份，列出樣本數。
4. 將原固定選股分成零成本、原費稅、原費稅加價格偏移三種描述性成本口徑。它們不會回頭改選股，不是可成交淨值或年報酬。
5. 用2023價格合格股票日的波動、成交金額與60日動能分布，固定三等分界線；不使用後來績效挑群。另按訊號當時0050過去60日正／非正報酬分組。分群是選股條件描述，沒有產業、市值、因果或同風險Alpha宣稱。
6. 拆解模型與基準的共同／獨有持股貢獻，以獨立逐筆端點查價及獨立聚合核對結果；完成有意義的邊界測試。
