# 研究接續與新機制來源試點（2026-10-20）

使用者已要求：不需要其決策時持續下一步。單一假說未過關，只結束該假說；階段完成、例行checkpoint或報告提交不代表整個專案應停止。本輪先比較四類有不同契約／執行條件的候選，再自動執行有限來源試點，沒有現在必須由使用者做的決定。

這是研究接續計畫，沒有新獲利結論、每日人工驗證、模型擬合或實際交易授權。舊七規則、風險控制、公告動能及其他已收束研究保持原決定；不改原參數、不重寫失敗紀錄。四候選的比較不是四個已完成報酬試驗，也不清零先前多重嘗試或已用年份的紀錄。

## 共通立項條件與資源上限

- 先找可明確定義的契約現金請求權或可驗收的對沖／結算關係，說明付款義務人、資格、日期、改約與失效條件；價格低於名目對價本身不是優勢。
- 用30萬元現金預算、實際整數交易單位核對買入價、費用、款項占用及壓力需求。不把面額或保證金當全部資金需求，不以必須借券的安排作必要前提。
- 在讀取該候選市場報酬前，先證明公開自動取得的事件母體、原始條款、發表時間、修正／失敗版本及保存路徑。只做成功案、事後挑價差或按已知結局換年份均不合格。
- 本輪最多啟動**兩個來源試點**：第一個為CB持有人賣回；若來源關卡失敗或不具本預算可核實的執行路徑，直接接現金法定併購。每個試點的發現階段最多**12個公開請求**，包含失敗請求及取得少數原條款的控制請求，不以換客戶端或重試偷偷延長。
- 實際請求前另凍結期間、市場、查詢清單、解析／覆蓋驗收及失敗條件。兩worker、共用來源鎖；依 `research_pipeline.py` 保存階段輸出，原件先封存、備份取回及SHA／CRC／manifest核對。只有hash驗證的階段可跳過。
- 不要求使用者逐份下載、不購買資料、不發送對人訊息、不擬合模型或下單。只有確實缺少無法自動取得的資料或憑證時，才指出必要項目；沒有現在要求使用者買SRF資料或提供券商帳號的理由。

12請求僅是來源發現預算，不能把少數控制頁當完整資料。若需要更大完整原件群才能立項，先記錄尚未通過的關卡，不能直接擴抓或跳到報酬。已用完兩個試點後，保留失敗證據與剩餘候選的具體資料界線；不得把例行checkpoint變成再次索取使用者確認，也不得默默追加第三個來源試點。

## 1. 優先：可轉換公司債持有人賣回

研究機制是合格持有人依發行條款，在指定期間向發行人行使現金賣回權。若存在可實際買到、扣完費用仍低於可收取淨額的價格，差額可能補償信用、申請、等待與流動性風險；應檢驗它是否超過這些風險與現金機會成本，不能預設一定有便宜債。

[TPEx債券介紹](https://www.tpex.org.tw/zh-tw/bond/service/introduction/tpex-bond.html)所述可轉債交易單位為**面額10萬元**。面額不是買入現金額：須依報價與費用核對整數單位，不能直接宣稱30萬元能買三單位。[權利行使資訊入口](https://www.tpex.org.tw/zh-tw/bond/issue/cbond/option.html)與公開賣回公告是待實測路線，目前未驗收該入口的自動回應、完整歷史母體或逐債條款。

來源試點須區分持有人賣回、到期償還與發行人贖回；保存債券代號、尚未到期身分、可賣回期間、每張／每面額價款、有效資格、申請方式、付款日，以及修正、提前贖回、轉換、下櫃與未付款紀錄。不能拿到期日替代賣回窗口，也不能把發行人贖回當持有人無條件權利。

若12請求內無法自動取得索引及條款／修正控制、無法驗收真實可行的整數單位資金路徑，或付款／信用狀態不明到不能定義請求權，就記錄來源失敗並接第2類。債券面額、賣回價與到期償付都不是保證；違約、費用與付款延遲仍需另外評估。資料通過後另凍結經濟協定，不立刻產生訊號。

## 2. 備援：純現金合併／法定現金股份轉換

只討論有明確新臺幣每股現金對價的法定全體股東移轉，與公開收購自願應賣／比例分配分開。取得現金的義務來自交易完成後的法律／契約安排，未完成前仍可能因核准、融資、股東決議、改價或撤銷而失效。原股東可能為立即收回資金而折價出售；這是待驗風險補償機制，不是已證明套利。

[企業併購法](https://law.moj.gov.tw/LawClass/LawAll.aspx?PCODE=J0080041)第4、22、29、31、33條提供現金對價、契約與股份轉換程序依據；[TWSE重大訊息程序第2條第11款](https://twse-regulation.twse.com.tw/TW/law/DAT0201.aspx?FLCODE=FL007111)包含重大變更、否決與撤銷。來源應從完整公告母體建立，而非只由[已下市名單](https://www.twse.com.tw/zh/listed/suspend-listing.html)挑完成案。

已保存的官方ezSearch UI列M11「發行有價證券、減資、併購或股份轉交換」。可沿既有自動JSON路徑先查固定一季TWSE非金融公司，對期間查詢與逐月分區核對；**M11的實際回應與母體仍未驗收**。G01名稱雖含合併分割收購，封存UI子項為公開收購文件／公告，不能僅憑類別名稱視為純現金法定合併全集。

資料須保留原公告、條件／對價更正、否決／撤銷、停止買賣、股權移轉及付款安排。固定季零案或上限內無法取得控制鏈，就收束來源試點，不換成事後有成功案的季／年；少數控制不計收益。先tender後強制轉換的同案標示重疊，不把兩個階段算成獨立樣本，也不重啟已收束的tender原件修復。

法律形式的稅務不同。[財政部97年函釋](https://law-out.mof.gov.tw/LawContent.aspx?id=GL004795&media=print)說明現金合併消滅個人股東的股利所得與取得成本證明；不能一概當普通上市股票交易所得處理，亦不把現金股份轉換與消滅合併塞入同一稅務公式。未核實付款與稅目以前，不算個人淨收益。

## 3. 不優先：現增認購權

舊專案的現增工作是股東權益與放棄認購帳務，沒有建立可執行獲利機制。本輪未識別可交易／可轉讓的權利市場、當時資格與可實現價差，不能把事後認購折價當任意新買入者能取得的利益。還須額外認購款、資格基準日、股票交付日與除權價格核對。

保留候選，沒有本輪來源請求配額；不為延續工作而把舊例外會計重寫成新alpha研究。

## 4. 保留資料界線：ETF現貨／期貨基差

這類機制要核對可共同取得或對沖的部位與結算規則；價差可能補償融資、股息、流動性及結算差異，不能只比較兩個收盤價。

直接AP申贖目前不適合30萬元：[0050 PCF](https://www.yuantaetfs.com/tradeInfo/pcf/0050)所列最低申贖單位為500,000受益權單位，與小資金直接申贖不相符。

另一條是SRF小型ETF期貨；[TAIFEX合約規格](https://www.taifex.com.tw/cht/2/sTF)列0050標的、每口1,000受益權單位。[2026-08-12保證金表](https://www.taifex.com.tw/cht/5/stockMarginingDetail)的原始8,700／維持6,700元只是交易所當表數字，**不是券商實收保證金，也不是完整資金需求**。現貨資金、期貨逐日損益／追繳壓力與整數口數都須算入。

到期為現金結算，結算價採標的最後60分鐘現貨成交價算術平均，不能以單筆收盤成交宣稱鎖定同一價格。免費[近30日成交資料](https://www.taifex.com.tw/cht/3/futPrevious30DaysSalesData)是成交紀錄，不能替代同步兩側可成交買賣價、數量與時間。當前缺同步深度／可執行證據與相關資料授權路徑，這是資料界線，**不是否定基差機制**，也不阻塞前兩項免費來源試點。現在無須請使用者買資料。

## 階段接續規則

目前沒有候選通過本輪新的來源／經濟／執行關卡。接續順序固定：**CB來源試點 → 未通過即現金法定併購來源試點**；通過來源的一項，另凍結其完整經濟與獨立證據驗證，不與尚未驗收的候選比事後最好報酬。

每一階段記錄實際請求與錯誤、輸入／輸出SHA及下一個可以自主執行的動作。結束單一假說時同步指出專案接續路線；只有真正缺少必要資料、憑證或已授權範圍外的實質決策，才向使用者提出具體問題。
