# 2026-10-18 來源方案替換：取消反覆手動補件

使用者要求嘗試解除阻礙；無法解除就說明原因並換方案，不進入反覆人工下載。本決定取代先前各輪報告中的「請另存某檔再提供路徑」待辦；舊報告、資料、協定及hash保留作歷程，不能視為仍待使用者處理的工作。

## 為何原路徑沒有完成

1. **傳輸／內容確實受阻。** 本輪兩個MOPS歷史公告POST都回HTTP200，但800-byte內容明示「因安全性考量無法呈現／THIS PAGE CAN NOT BE ACCESSED」。不能只檢查200就當已取得公告。聯電後續SEC完整申報回HTTP403。先前Business Wire的TimeoutError及其他403仍是先前觀察。這些現象無法證明特定IP、帳號、Cookie、雲平台或網站根因，沒有將猜測當診斷。
2. **可操作命令不等於可操作瀏覽器GUI。** Desktop Commander的可用工具提供命令／檔案存取，沒有頁面點擊能力；也未讀取瀏覽器登入資料、改執行政策或繞過驗證。
3. **研究流程讓取得負擔先於可行性判斷。** 原協定確實需要可驗證歷史文件／版本／時間；SEC接受不等於台灣首次公開，單份PDF不證明完整修訂。但兩家公司小型來源試點尚未完成數值面板，就不斷追逐這些證據並請使用者逐檔處理，已偏離低成本試點目的。這是工作順序與投入決策需要修正，不能只把缺檔繼續交給使用者。

## 現在採用的方案及已完成成果

另立[新協定](../configs/operating_snapshot_protocol_20261018.json)，不修改10/16原協定，不宣稱其PIT關卡已過。研究用途改成**可追溯的公司資料擷取與本次選用版本的回顧算術**。不是歷史即時特徵、獨立預測驗證或交易績效。

- 固定台積電／聯電、2023Q1～2025Q4，共24公司季。官方季報頁自動發現PDF，聯電採官方文件規律；只有連結發現可採web工具解析，實際數值必須來自封存取回的原文。

- 原文、錯誤回應、metadata及來源配置先封存，再Windows備份取回，SHA／manifest／CRC通過後解析。大檔留在inputs及Windows研究備份，Git僅存程式、配置、小型報告／收據。

結果、逐列來源及限制見[本輪報告](../deliverables/operating_replan_20261018/report.md)。全部歷史建模readiness仍為False；原七規則每日計畫仍停止。
