# 台股 ML 選股模型 v1：研究規格

最新進度（2026-10-10）：原 20 日飆股分支保留；已新增免費法人、延遲靜態營收、信用特徵及使用者採用的 60 日相對報酬／每月 Top15 研究。60 日是預測期間，持股依每月排名續抱或退出；合成報價資金代理不等於實際零股成交或實股 NAV。

現況、固定設計、跨年結果與重跑入口見 [60 日研究說明](MEDIUM_TERM_RESEARCH.md)，最新檢核進度統一放在 [Tasks](RESEARCH_PRIORITIES.md)。飆股分數未校準，60 日分數是預期相對報酬；兩者都不是預測價格模型。

## 1. 研究問題

**原始研究藍圖**是在每個換股日預測未來 20 個交易日相對 0050 報酬並排序。**目前已實作的 2025–2026 飆股分支**則用量價特徵對未來 20 個市場日最高還原價達 +30% 的事件給出未校準 Logistic 分數；這不是已校準的機率，也沒有預測價或預測報酬過濾。詳見文末 30 萬元 Top 15 分支。

\[
y_{i,t}=R_{i,t\rightarrow t+20}-R_{0050,t\rightarrow t+20}
\]

第一版的核心問題：模型挑出的前 10% 股票，在未參與訓練的期間，扣除交易成本後是否能長期勝過 0050 與等權重股票池？

## 2. 第一版範圍

| 項目 | 設定 |
|---|---|
| 市場 | 台灣上市普通股 |
| 資料頻率 | 日線；月營收按實際公布日加入 |
| 股票池 | 歷史上市普通股（含第一上市 KY、創新板）；排除 ETF、TDR、權證、特別股；流動性規則另訂 |
| 預測週期 | 未來 20 個交易日 |
| 換股頻率 | 每月一次 |
| 投資組合 | 預測排名前 10%，等權重 |
| Benchmark | 0050、股票池等權重 |
| 第一版模型 | Linear baseline、LightGBM |
| 驗證方法 | Walk-forward、完全依時間切分 |

## 3. 特徵

第一階段先用容易取得且時間點明確的資料：

- 動能：5、20、60、120 日報酬率
- 相對動能：個股同期報酬減 0050 同期報酬
- 趨勢：收盤價相對 MA20、MA60、MA120 的距離
- 波動：20、60 日報酬標準差、ATR
- 成交量：成交量相對 20、60 日均量，成交額與流動性
- 基本面：月營收年增率、月增率及近三個月趨勢
- 可選第二階段：本益比、股價淨值比、ROE、法人買賣超、融資融券

所有基本面與籌碼資料必須以「市場當時可取得日期」對齊，不能用現在整理好的季度欄位回填過去。

## 4. 資料切分與回測

禁止 random split。建議初始切分：

- 2016–2021：初始訓練
- 2022：第一段測試
- 之後逐年擴張訓練窗並測試下一年

每個換股日只使用該日以前已知的資訊。交易假設至少計入：

- 券商手續費
- 賣出交易稅
- 滑價
- 漲跌停或無成交造成的不可交易情形

避免 20 日標籤互相重疊造成驗證污染；若訓練邊界靠近測試區間，需要 purge/embargo。

## 5. 評估指標

模型層：

- Spearman rank IC
- Top-decile 與 Bottom-decile 的未來相對報酬差
- 各年度 IC 與穩定性

投資組合層：

- CAGR、年化波動、Sharpe ratio
- Maximum drawdown
- 相對 0050 的 alpha 與勝率
- Turnover 與扣成本後報酬
- 不同市場階段的表現

準確率與 RMSE 僅作輔助，不作是否可交易的主要判準。

## 6. Baseline

在訓練 ML 前先完成三組基準：

1. 買進並持有 0050。
2. 股票池等權重、每月再平衡。
3. 只依 12 個月動能排序，跳過最近 1 個月。

LightGBM 必須在相同股票池、換股日、成本與回測規則下勝過這些 baseline，否則不能把績效歸功於模型。

## 8. 實作順序

1. 選定資料來源與可取得的歷史期間。
2. 建立不含未來資訊的標準化日線資料表。
3. 完成股票池規則、label 與 baseline 回測。
4. 加入價格、成交量與月營收特徵。
5. 訓練線性模型與 LightGBM，執行 walk-forward。
6. 加入成本、不可成交限制及績效報告。
7. 最後才評估是否加入估值、法人與深度學習特徵。

## 9. 第一個里程碑

先完成「資料健康檢查 + baseline 回測」，不急著訓練模型。輸出應能回答：

- 每個交易日股票池有多少股票？
- 是否存在倖存者偏差或下市股票缺漏？
- 價格是否已正確還原除權息？
- 月營收是否按公布日期對齊？
- 0050、等權重與動能策略在相同成本假設下表現如何？

只有這一層可信，後續 ML 的結果才有意義。

第一版採官方資料優先：

| 資料 | 免費來源 | 第一版用途 | 注意事項 |
|---|---|---|---|
| 上市公司清單 | TWSE OpenAPI `t187ap03_L` | 建立當前股票清單與產業欄位 | 只有當前清單不足以消除倖存者偏差 |
| 上市每日行情 | TWSE `MI_INDEX` | OHLC、成交量、成交額、當日本益比 | 一天一請求；需快取並限速 |
| 上櫃每日行情 | TPEx OpenAPI | 第二階段擴充股票池 | 第一版先只做上市股票 |
| 月營收 | MOPS／TWSE OpenAPI | 營收成長特徵 | 必須保存公布日，不可直接回填到營收月份 |
| 除權息 | TWSE 除權除息資料 | 建立還原價格 | ETF 配息與個股公司行動要分開處理 |

下載程式 `twse_free_data.py` 不需要 API key，會保存原始 JSON 和正規化 CSV。範例：

```bash
# 單日煙霧測試
python3 twse_free_data.py --start 2026-09-02 --output data/raw/twse

# 小範圍測試；休市日會自動略過
python3 twse_free_data.py \
  --start 2026-08-01 \
  --end 2026-09-02 \
  --output data/raw/twse \
  --delay 3
```

不建議一開始直接抓十年。先跑一個月、檢查欄位與交易日，再按年度分批下載。官方介面沒有承諾適合高頻大量擷取，因此保留 3 秒間隔、保存 raw response，失敗後也能續跑。

## 13. 飆股 label v1 與 2025 原型結果（封存）

本節保留第一版實驗紀錄。舊版窗口允許局部缺價，且使用今日公司名單及未還原價格；不再作為後續訓練資料。新版定義與結果見第 14 節。

研究事件：

\[
y^{event}_{i,t}=1
\quad\text{if}\quad
\max_{1\le k\le20}
\left(\frac{High_{i,t+k}}{Close_{i,t}}-1\right)\ge30\%
\]

隔日開盤觀測口徑將分母改為下一個市場交易日的開盤價；若下一交易日停牌或沒有開盤價，該筆留空。這不是已驗證可成交的 label。預測窗口依全市場交易日曆計算，不會因個股停牌而延長。

| 門檻 | 研究事件率 | 隔日開盤口徑事件率 |
|---:|---:|---:|
| 20% | 10.07% | 9.66% |
| 30% | 4.39% | 4.20% |
| 50% | 1.16% | 1.10% |

30% 門檻的 2025 原型結果：

- 目前公司清單過濾後共有 254,072 列、1,069 支股票。
- 舊版判為可用的樣本為 232,822 列、1,067 支股票；未嚴格排除窗口內局部缺價。
- 正例 10,222 列，正例率 4.39%。
- 隔日開盤可評估樣本 232,187 列，正例 9,761 列，正例率 4.20%。
- 635 筆因下一市場交易日缺少開盤價而不能建立隔日開盤口徑 label。
