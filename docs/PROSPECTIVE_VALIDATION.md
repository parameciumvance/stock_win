## 操作入口

```bash
python3 -m unittest test_prospective_journal -v
python3 prospective_journal.py snapshot path/to/raw.html --key revenue_202609_first
python3 prospective_journal.py verify deliverables/prospective_journal/snapshot/revenue_202609_first.json
```

snapshot只保存當下提供檔案的觀測，檔案內的歷史日期不能冒充原始首次公開日期。signal JSON須提供signal_date、status、protocol_sha256及complete時的snapshot_records；每日key須等於訊號日期。
