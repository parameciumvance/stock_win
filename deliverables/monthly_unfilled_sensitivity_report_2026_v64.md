# 2026 月度標籤：單價近漲停買入「完全未成交」診斷

沿 v62 九次月度固定名單及 v63 換股日日線，將「新買入、整天單一價格、當日開盤相對訊號日前收至少 +9.5%」的項目標成**可能難以進場**。情境假設七筆方法／股票月的買單全未成交，在當月排名的分母維持原 Top 10% 檔數、但這些股票即使後來符合 +30% 標籤也不給正例 credit。不替補股票，不模擬現金與退出，也不把此情境當成實際交易事實。

## Tasks

- [x] 九個月每法各 616 檔次；Logistic 6 筆、60 日去近 5 日動能 1 筆被標記。Logistic 六筆中五筆原本為訊號日收盤分母的正例；次日開盤分母則有兩筆。動能一筆為收盤分母正例，隔日開盤分母非正例。
- [x] 固定分母、假設全部標記買單零 credit，Logistic 的九次月度正例率由 **37.42% → 36.65%**，動能由 **31.40% → 31.24%**；模型對規則差額由 **+6.02 → +5.40 百分點**。
- [x] 改用次日開盤標籤，Logistic **36.25% → 35.93%**，動能 **30.81% → 30.81%**；模型差額由 **+5.44 → +5.12 百分點**。
- [ ] 這些是事後看換股日 OHLCV 才能標記的**標籤分數敏感性**。當日有全日成交量，不能斷言全數買不到；也沒有委託量、排序順位、現金與可用資金、留存舊股及費稅，不能由此推算 NAV 或淨 Alpha。

上述數值顯示少數可能排隊的新進股使原月度標籤差額約少 **0.62 個百分點**（收盤分母情境），不消除排名上的標籤差異。但它不能解答真正重要的「買不到時資金停在哪裡、退出股賣不賣得掉，以及全程淨值多少」；全日單價和近 10% 也只是資料啟發式，正式漲跌停與可成交量需逐筆交易資料或保守、公開的撮合假設。
