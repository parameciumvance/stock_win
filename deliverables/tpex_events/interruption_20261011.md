# 2026-10-11 上櫃執行中斷與可恢復狀態

四年上櫃法人來源在執行環境離線前已完成下載、日期／加總及正規化讀回：905市場日、754,372筆全證券法人紀錄。2025為243日／204,662筆，2026截至10/02為181日／164,102筆。來源 metadata 已記錄在各年 acquisition.json；2025與2026的原始來源包尚未封存取回，不能當成已保存完成。

事件規則「已驗收」結果只到2024。2025共同池 gzip 重播時拋出 EOFError，未通過完整性檢核；該年的初步均值不列為已驗證結論，2026完整事件比較仍 pending。

隨後本機執行工具回報 `409 Conflict, environment_offline: Environment is not connected`；一次唯讀 pwd 指令也在30秒內沒有回應。可確認平台執行環境離線，平台沒有提供斷線的底層原因。GitHub介面仍可用，所以以repo保存修復與進度。沒有執行環境重啟工具。

修復將每日表、選股與共同池改為寫暫存檔、完整關閉、串流讀回所有CSV列（包含gzip結尾檢核）後才原子發布；增加輸出SHA與完成標記。釋放不再使用的資料表，重播以行索引取代重複持有所有群組資料表。規則、45／60日延遲、成本、20／60日端點、Ridge參數與既有分數均未改變。兩项新回歸測試已加入，環境離線後尚未執行；不能宣稱修復已驗收。

既有43項TPEx測試在此修復前通過。量價固定模型的空白資料目錄還原重播四檔SHA相同；2023及2024事件選股已逐筆驗證並封存取回，原來源與研究限制均保留。

下一步：恢復環境後先核對四年快取與已保存輸入，執行新增測試，再用固定配置重建2025、2026事件結果、完整重播與資料包取回。嚴格營收公告PIT、完整停牌主檔、精確股東現金帳仍pending，不擴大調參。
