# 2026 月度名單：無公司行動完整報價路徑的價格觀察

沿 v62 九次月度名單，觀察**預定進場日的原始開盤價 → 下個月第一個交易日的原始開盤價**。只保留區間（含進出日）每個市場日均有完整價量、且已登錄公司行動為零的股票月。未對保留或排除的股票模擬持股、成交、費稅、滑價、股利或其他權益，以下不是交易策略 NAV、年化績效或 Alpha。

## Tasks

- [x] 九個進場日至下月初（01-02→02-02 至 09-01→10-01）均有市場日曆。Logistic／60 日去近 5 日動能原名單各 616 股票月，其中無公司行動且全程完整價量為 **554／547**（89.9%／88.8% 股票月）。其餘 **62／69** 筆至少一個公司行動，兩方法均無全程缺價／無量的入選股票月。
- [x] 無事件子樣本各月入選股票的原價開盤到次月初開盤報價，按**九個月各月平均再簡單平均**，Logistic **+8.66%**、動能 **+6.92%**，差 **+1.74 個百分點**。每方法九個月有 8 個子樣本月平均為正；07-01→08-03 兩法卻分別為 **-32.20%／-31.57%**。不連乘月報價，也不當作整體組合報酬。
- [x] 逐列核對無事件區間的原價與因果調整價開盤報酬一致。已登錄公司行動造成的因子跨期變動另列，避免把除息或有償認股價差當成單純股價報酬。
- [ ] 6～7 月公司行動密集，Logistic 無事件覆蓋率僅 73.6%／62.7%，動能 72.2%／62.7%；**排除不是隨機**，各方法有效樣本也不同。排除者的收益、股數、認購款或退出現金流未計入，不可把 +1.74 個百分點宣稱淨 Alpha。
- [ ] 日線開盤報價無法證明當時的指定買賣量可成交；單價日和委託排隊、完整公司權利與交易成本仍待補。
