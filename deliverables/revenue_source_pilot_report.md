## 發現與限制

1. 台積電新聞稿可見的 Issued on 日期能確認到日；其 JSON-LD `datePublished` 三份均為 1970 年錯誤預設值。`dateModified` 和固定鐘點的 `time datetime` 也不作首次公開時刻。解析器只取可見日期。
2. SEC 6-K 同時包含四捨五入的百萬元新聞稿表與精確到千元的明細。解析器使用後者，再核對公告年增率的四捨五入差距。
3. 官方 SEC submissions JSON 是本次取得的索引快照；索引、文件、表單和時間須一致才接受。原始文件與 metadata 的 SHA-256 一併保存；不宣稱修正歷史已完整調查。
4. 本次舊版 MOPS 查詢 URL 回傳 HTTP 200，卻重新導向 error 頁面，沒有公告資料。保存錯誤回應證據；不能把 HTTP 200 當擷取成功，也不能因此斷言所有官方歷史查詢都不可取得。
5. 美上市公司的 SEC 路線覆蓋範圍有限，不能用這三筆推論全台股可免費取得完整時點資料。
6. 當前已存回應的 bytes/SHA 和歷史申報文件均可重查；今天才下載的新聞稿不是在 2024 年採集的網站快照。

## 重跑

先還原 `revenue_pilot_raw_20261005.zip` 到專案根目錄。它包含 `inputs/revenue_pilot/`、三份交易日曆與原始 metadata；code/config/output 留在本 repo。

```bash
python -m twse_history.revenue_pilot
python -m unittest twse_history.test_revenue_pilot -v
```

缺少快取會停止；只有明確加入 `--fetch` 才從設定檔下載缺少來源，已有快取不覆寫。每份快取須與記錄的來源和 SHA-256 相符。當前 submissions JSON 未來若刪除較舊 accession，新抓資料可能不再涵蓋本試點，應使用已封存快照，不自動補造。

官方来源：設定檔 `configs/revenue_pilot.json` 列出原文、索引及 submissions URL。研究輸出：`deliverables/revenue_source_pilot.json`。
