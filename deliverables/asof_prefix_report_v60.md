# 2026 訊號的截點一致性檢查

以相同官方行情與公司行動封存，分別重新建截至 2026-06-30、09-02 的資料，再和截至 10-02 的全期間重建表裁至同日比較。這是**資料處理程式的前綴一致性**檢查，不能證明回溯下載的公司行動與證券分類在各過去日期已經正式發布。

## Tasks

- [x] 6/30 截點：840 個市場日，857,743 筆共同價格列的原價、因果調整價、因子與證券角色全部一致；2026 年 126,440 筆共同特徵列的 13 個模型特徵、訊號資格和歷史成交額全部一致。
- [x] 9/02 截點：885 個市場日，906,414 筆共同價格列與 176,456 筆 2026 年特徵列，同樣在上述因果欄位零差異。此截點已越過 8/18 的 `6225` 除權事件。
- [x] 明確避用依後續事件追溯改寫的反向還原因子：在 6/30、9/02 截點，它和 10/02 全期間值分別有 442,511／39,310 筆共同價格列不同。模型的 13 項特徵用因果調整價，不用反向還原價。
- [ ] 待補每日 ISIN／上市下市時點快照，以及公司事件原始公告的發布時間／修訂紀錄。已重建出的事件生效日不能取代當時正式公開時點。

執行 `build_multiyear --as-of 2026-06-30` 與 `--as-of 2026-09-02`，再用 `audit_asof_prefix_v60.py` 對照同一份 10/02 重建表；兩個 JSON 保存筆數、欄位與所有差異計數。訓練時未使用的 `relative_return20` 是未來目標，不列為因果特徵比對項目；尚未結束的 20 日標籤也沒有參與各截點的模型分數。

這些結果支持 v58 當日訊號在**現有回溯資料與程式**下不會因加入後來行情而改變。它不消除 `3149`、`4989`、`6225` 權利價值、9/28 舊分類快照、公告時點和實股成交成本的限制。
