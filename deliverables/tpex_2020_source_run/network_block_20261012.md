# 2020 來源進度與網路阻擋

2021全年來源已完成。2020行情245日／216,362筆，575個封存檔保存取回核對通過。法人本地快取62／245日，最後2020-04-10；完整1–3月56日／34,157筆、114個封存檔已保存取回核對。

下載退出碼1，來源錯誤為 `Tunnel connection failed: 403 Forbidden`；工具另回報 `network approval was cancelled before a decision was returned`。這是本次代理連線阻擋的觀察，不是櫃買中心拒絕連線或前次exec-server斷線根因的證據。

離線檢查：2020共965筆事件，957筆前收吻合、5筆不吻合、3筆缺2019前期。2020資料補入後2021年初唯一缺前收已解，2021共985筆吻合、2筆不吻合；新報告隔離保存，沒有覆寫舊研究結果。
