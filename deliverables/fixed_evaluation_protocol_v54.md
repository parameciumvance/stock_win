# 台股飆股排序：後續資料固定評估流程

本流程於 2026-10-03 記錄。2024、2025 的資料、模型比較及各種門檻敏感性都已檢視，屬**已使用的探索資料**。本文件固定未來重算的口徑，不能回頭把既有結果稱作事前預註冊驗證。

## 固定設定

| 項目 | 後續固定口徑 |
|---|---|
| 股票池 | 每個訊號日當時的 TWSE 上市普通股；依歷史行情、證券分類與上市／下市事件重建，不用今天仍上市的名單回填。 |
| 時點 | 訊號日收盤後才可使用當日量價特徵；要測實際委託，買入安排在下一市場日。 |
| 主標籤 | 未來 20 個市場交易日內的調整後最高價相對訊號日調整後收盤價上漲至少 30%，要求完整未來窗口。 |
| 次標籤 | 同一未來窗口的最高價相對下一市場日調整後開盤價上漲至少 30%，只在該日有效開盤價可得時評估。此項仍是事件標籤，非實際賣價。 |
| 特徵 | 既有 v5 的 13 個因果量價欄位，使用當日或更早資料；保留 2429 已知權益異常標籤隔離。 |
| 模型 | 既有 v5 Logistic 標準化管線及 HistGradientBoosting 固定參數；不根據 2025 後看結果調參。 |
| 主要規則 | `mom60_skip5`；`mom20` 為次要對照。 |
| 合格股票 | 完整 120 市場日歷史、訊號日原價至少 10 元、正成交量、過去 20 日平均成交額至少 1,000 萬元、特徵有限值。 |
| 主要排名 | 每日同一合格股票池最高分 `ceil(10% × 合格股票數)`，比較等權逐日標籤正例率的成對差與 PR-AUC。 |
| 次要敏感性 | 前 5%／20% 和平均成交額至少 3,000 萬／1 億元，保持模型分數不變，另列報告；不能用探索結果取代主要口徑。 |
| 時間切分 | 訓練資料的 `label_window_end` 必須嚴格早於測試起日；按年度向前，逐折重新建立標籤與特徵，禁止隨機分割或未來公告滲漏。 |
| 分段呈現 | 每個年度獨立列出樣本數、可評估日、入池率、正例率、前 10% 正例率與模型－規則差額；不以合併平均掩蓋年度符號反轉。 |

2024 短訓練兩折及 2025 留出集已被反覆分析。新增 2023 年可延長訓練與檢查歷史折，但 2024／2025 仍是**已看過的年份**；若要較有說服力的未使用年度，需完整取得之後未曾用於選規則的年度，並在檢視其標籤前保持上述設定不變。先前 2024 年 Logistic 對主要規則的差額為 -0.31 個百分點，2025 年為 +3.19 個百分點，表示目前不能報稱跨年度穩定。

## 資料與績效閘門

1. **資料完整性：**逐年核對 12 個官方月交易日曆及每日行情；保存原始回應、來源和雜湊。公司行動統一跨年還原，股票池包括下市／新上市；缺價、停牌、年末不足窗口與缺當日收盤要各自標記。缺標籤不當作負例。
2. **實股 NAV：**持股權益、股數、現金及發放時點、證書與普通股行情、停牌估值、整股畸零及成交限制都核實後，才用同一成本口徑比較全年實股組合。前 10% 飆股正例率和未來最高價不換算成策略報酬或 Alpha。

## 下一步規劃

目前 2023 年官方原始行情尚未提供，這個執行環境連證交所資料端點曾逾時；證書行情與結算已另列 pending。資料一旦可用，先通過完整性閘門，再執行固定流程及逐年報告。任何研究設定變更另開版本，保留原定結果。
